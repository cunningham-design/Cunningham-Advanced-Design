Cunningham Advanced Design website

Files:
- index.html
- style.css
- script.js

To publish with GitHub Pages:
1. Create a new public GitHub repository.
2. Upload these three files to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main / root and Save.
6. After GitHub publishes the site, add cunningham-design.com under Custom domain.
7. Update only the website DNS records at GoDaddy. Do not remove Microsoft 365 MX/TXT/CNAME records used for email.
